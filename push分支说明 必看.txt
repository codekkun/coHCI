feat-audio 处理听觉反馈和粒子特效（声音查找，代码中显示声音）
docs-ppt 文档和ppt
feat-ui 处理图片 （图片的查找，代码中显示图片）
feat-core （底层逻辑）
bugs（用来修改bug所用的分支）

说明基本工作流

各个组员在群聊中领取任务，
比如A领取到了找图片或者在网页中显示图片的任务（写代码）
那么他就应该 pull main分支
进入 git checkout -b feat-ui # 进入图片修改分支
修改完毕之后
git commit -m "feat-ui 加入了什么什么图片 得以显示什么什么图片"
然后再git push origin feat-ui
再去网页上提交PR 也就是合并到主分支的请求 我会审核检查冲突然后同意合并

第二天 切换到git checkout main 切换到主分支然后拉取最新成果再进行更改
注意进入到对应的修改分支之后再进行修改
